# SkyCast – Weather Forecast App

SkyCast is a modern, responsive weather forecasting web application built using **Java, Spring Boot, HTML, CSS, and JavaScript**. It provides real-time weather information, hourly forecasts, a 7-day forecast, humidity, wind speed, and sunrise/sunset timings using the Open-Meteo API.

The application also includes an interactive sidebar with games, featuring an API-powered Trivia Quiz using the Open Trivia Database and a Number Guessing game. SkyCast combines useful weather insights with entertainment in a user-friendly dashboard.

## Features
- Live weather updates by city search
- Current weather conditions and 24-hour forecast
- 7-day weather forecast
- Celsius and Fahrenheit temperature conversion
- Location-based weather search
- Interactive sidebar navigation
- Trivia Quiz integrated with an external API
- Number Guessing game
- Responsive, modern dark-themed UI

## Technologies Used
- Java and Spring Boot
- HTML5, CSS3, JavaScript
- Open-Meteo Weather API
- Open Trivia Database API
- Maven
